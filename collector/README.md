# Symbio Agent Collector

Run the command generated by **发现与入职 → 配对新机器** on a machine running Node.js 22.13 or newer. It pairs the machine, reports the first scan, and continues reporting until stopped.

To resume an existing pairing:

```sh
npx --yes --package=symbio-agent-collector@0.1.0 -- symbio-agent-collector run
```

Use `run --once` to check connectivity or `scan` to inspect the local inventory. The collector saves its pairing in `~/.agent-office/collector.json`. Set `OFFICE_COLLECTOR_CONFIG` to use a different file.

The receiver must be reachable by the target machine over HTTPS or through an SSH tunnel. See the [deployment guide](https://github.com/wang-zhengxin/symbio-agent/blob/main/docs/DEPLOYMENT.md#5-接入远程采集机器) for connection and revocation steps.
