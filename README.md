# Symbio Agent · 人机共生多智能体协作工作台

[English](README.en.md) · [部署与运维手册](docs/DEPLOYMENT.md) · [运行器接入指南](docs/AGENT_ONBOARDING.md) · [远程采集客户端](docs/REMOTE_COLLECTOR_GUIDE.md) · [GitHub 授权说明](docs/GITHUB_INTEGRATION.md)

**Symbio Agent** 是一套本地优先（Local-First）的多 Agent 与真人协同办公工作台。它将真人成员与 Codex、Pi 等 AI 智能体汇聚在同一座可交互的 **3D 数字办公室** 中，统一管理空间建造、工位分配、小队组织、Skills、MCP 工具、任务流转、会议讨论、项目文件验收与三级 Token 预算。所有状态与执行事件持久化于本地 SQLite，并通过 SSE 实时同步到浏览器。

---

## 核心亮点

- **3D 数字办公室与从零自建空间**：既支持在默认户型上扩建工位与自由增设隔墙/家具，也支持切换至 **「从零自建空间」**（`24m × 20m` 建筑蓝图），按 **画正交墙与门洞（近距离磁吸无缝转角）→ 铺多材质地板（或一键按墙体铺满）→ 放工位、功能区与摆件** 三步搭建专属办公室，并自动启用 2D A\* 避障穿门寻路、24 小时实时光影与独立随机错峰休息调度。
- **多运行器自动发现与异机采集**：内置本机扫描与独立采集客户端 `symbio`（`symbio-agent-collector`），自动识别 Codex、Pi、Claude Code、Gemini CLI、OpenCode、Aider、Cursor Agent、Copilot CLI、Qwen Code、Kiro CLI、OpenClaw、WorkBuddy、Antigravity 等运行器；运行器接入与员工建档解耦，支持多人复用同一运行器。
- **全周期组织与能力治理**：支持真人/Agent 混合小队、在线目录一键下载 Skills 或导入 `SKILL.md`、Streamable HTTP / stdio 协议 MCP 白名单、GitHub 仓库级工具授权；小队、技能、MCP、标签与自定义属性均支持原子化级联安全删除并记录操作审计。
- **任务流转、多人会议与三方对比验收**：任务支持看板/列表/表格三视图、一次性定时派发、子任务拆分与 `@` 提及讨论；支持双人交流与三人以上自动转入会议室多轮发言；项目公共工作区支持开工基线、当前版本与本次交付的三方对比发布及冲突拦截。
- **三级 Token 预算与安全沙箱**：按公司、小队、员工三级预留与扣减 Token 额度，执行前准入控制防超支；默认仅监听 `127.0.0.1` 回环地址，支持管理员/普通成员双角色权限隔离与只读/工作目录沙箱约束。

## 快速开始

### 环境要求与启动

需要 **Node.js 22.13** 或更高版本。安装依赖、构建产品说明主页并启动本机工作台：

```sh
npm install
npm start
```

启动后即可访问：

- **产品介绍与交互说明页**：`http://127.0.0.1:4317/`（源码位于 `apogee/`，开发调试可运行 `npm run dev`，单独构建可运行 `npm run build`）
- **Symbio 本机工作台**：`http://127.0.0.1:4317/office`

首次打开工作台将引导创建首位管理员，并自动初始化默认研发小队、交付核对技能与初始员工档案。

### 账号注册、邮箱验证与 SMTP 配置

首位管理员及后续新成员均通过邮箱验证码注册：

- 成员在登录页点击 **「注册账号」** 提交申请，管理员在 **「设置 → 工作区管理 → 账号与权限」** 审批启用、调整角色或停用账号；尚未绑定邮箱的旧账号登录后需先完成邮箱验证。
- 用户可在 **「设置 → 通知」** 开启或关闭评论 `@` 邮件提醒（默认关闭）；站内收件箱始终同步接收 `@` 通知。

在项目根目录创建 `.env`（或在进程环境变量中设置）配置 SMTP 后重启 `npm start`：

```dotenv
OFFICE_SMTP_HOST=smtp.example.com
OFFICE_SMTP_PORT=587
OFFICE_SMTP_FROM=workspace@example.com
OFFICE_SMTP_USER=workspace@example.com
OFFICE_SMTP_PASS="你的 SMTP 授权码"
```

默认使用 587 端口（STARTTLS）；465 端口自动启用隐式 TLS，其他端口可通过 `OFFICE_SMTP_SECURE=1` 开启直接 TLS；免认证内网中继可省略用户名与密码。验证码 10 分钟内有效，同一邮箱发送冷却 60 秒。

### 常用环境变量

| 环境变量 | 默认值 | 用途 |
| --- | --- | --- |
| `OFFICE_PORT` | `4317` | 本机 HTTP 端口（仅监听 IPv4 回环地址） |
| `OFFICE_DATA_DIR` | 项目根目录 `data/` | SQLite 数据库、技能包、项目公共工作区与执行目录 |
| `OFFICE_CONCURRENCY` | 使用「运行时」设置（初始 `3`） | 覆盖工作台最大并发执行数 |
| `OFFICE_CODEX_BIN` | `codex` | Codex CLI 可执行路径 |
| `OFFICE_PI_BIN` | `pi` | Pi CLI 可执行路径 |
| `OFFICE_PI_PROVIDER_EXTENSION` | 未设置 | 可选，受信任的 Pi 模型提供商扩展绝对路径 |
| `OFFICE_COLLECTOR_PORT` | `OFFICE_PORT + 1`（默认 `4318`） | 独立远程采集监听端口，设为 `0` 可关闭 |
| `OFFICE_COLLECTOR_HOST` | `127.0.0.1` | 采集端口监听地址 |

> 同一数据目录仅运行一个服务实例。后台常驻、反向代理、升级及备份恢复请见 [部署与运维手册](docs/DEPLOYMENT.md)。

## 3D 数字办公室与从零自建空间

### 1. 实时 3D 办公场景（`数字办公室 → 办公室`）

- **人物形象与状态联动**：内置 8 套 3D 角色外观（建档/编辑时可实时 3D 预览动作），角色位置与姿态实时同步任务执行、思考、审批、双人交流与多人会议状态。
- **固定功能席位**：前台固定在接待位，当前管理员绑定的真人老板固定在独立行政办公桌。
- **24 小时自然光影**：自动随当前时区实时演化清晨、上午、正午、黄昏、傍晚、深夜光照，也可点击工具栏光影按钮一键切换预览不同时段氛围。
- **独立随机错峰休息**：每位空闲员工拥有各自独立的随机休息计时（连续空闲 30–60 分钟后自动寻找空置休息座位小憩 5–10 分钟，再自行回到工位），避免所有角色同步扎堆起身；一旦收到新任务或会议邀请立即中断休息返回工作。
- **大屏模式与平面视图**：支持从任务页或项目看板进入全屏 3D 大屏模式，点击任意角色在右侧抽屉查看状态与关联任务；也可切换平面视图查看已发布区域布局。

### 2. 自由布置与从零自建空间（`空间与工位 → 自由布置`）

在 **「空间与工位 → 自由布置」** 中，提供 **「默认户型扩展」** 与 **「从零自建空间」** 两种建造模式，保存后原子化写入 SQLite 并实时同步至办公室、空间布局与工位管理：

1. **第一步 · 绘制墙面（支持先于地板绘制）**
   - 在 `24m × 20m`（`0.5m` 网格）空白蓝图上拉线绘制正交外墙/隔墙，支持 4 种墙面色板（灰绿 / 岩蓝 / 暖米 / 雾紫）。
   - **近距离磁吸与无缝转角**：起笔或拖拽终点靠近已有墙角/墙面（`≤ 0.85m`）或远处转角轴线（`≤ 0.72m`）时，自动磁吸对齐并高亮绿色/青色目标圆环、信标立柱与对齐虚线；L 型与 T 型转角在墙身、白色顶帽与深色踢脚线三层自动无缝融合，彻底消除拐角缝隙；按住 `Alt`（Mac 为 `Option`）可临时关闭磁吸。
   - **开门洞与拆墙**：点击墙面即可切开 `1.4m` 带过梁门框的可通行门洞（也支持在右侧属性面板一键「居中开门洞」或封堵门洞），2D A\* 寻路自动绕开墙体并穿过门洞。
2. **第二步 · 铺设地板与地毯**
   - 支持拖拽矩形拼接多块地板，提供 **编织地毯 / 暖橡木 / 浅灰石 / 灰绿砖** 4 种程序化纹理材质，边缘自动吸附墙角与相邻地板，可随时选中切换材质或拆除（有家具承载时受保护防误删）。
   - 提供 **「✨ 按墙体外框一键铺满地板」** 快捷按钮，画完外墙后一键生成贴合外框的地板。
   - 支持在地板上铺设 4 色区域地毯（暖沙 / 苔绿 / 雾蓝 / 陶土），不阻挡角色行走与家具摆放。
3. **第三步 · 摆放工位、功能区与摆件**
   - 家具与地毯必须放置在已铺设的地板之上，具备实时绿/红碰撞预览与 2D A\* 动态避障。
   - **可入座工位**：`工位桌椅`（自动分配 `D-01..` 编号，入座后受保护不可删除但可移动与旋转）。
   - **4 种功能区核心设施**：`老板办公桌`、`前台接待台`、`会议长桌`（6 席）、`休息长桌`（6 席）——在自建空间中摆放后，管理员、前台、多人会议与错峰休息角色会自动入座对应功能区。
   - **8 种办公摆件**：绿植盆栽、木质书架、磨砂隔断、休闲圆桌、双人沙发、移动白板、AI 机柜、迷你咖啡台。
   - **常用快捷键**：`R` 旋转 90° · `Delete / Backspace` 删除选中项 · `⌘/Ctrl + Z` 撤销 · `⌘/Ctrl + Shift + Z` 重做 · `Esc` 退出当前工具 · 按住 `Alt` 临时关闭磁吸。

## 工作空间导航与任务流转

侧栏按使用场景组织（普通成员仅显示授权页面），右上角头像菜单支持键盘方向键与 `Esc` 快速操作，全局按 `⌘/Ctrl + K` 随时搜索项目、任务编号与员工：

| 分组 | 入口 | 用途 |
| --- | --- | --- |
| 快捷入口 | 搜索、新建任务、收件箱、我的任务、聊天 | 检索内容、处理 `@` 通知、个人任务与多轮会议讨论 |
| 工作 | 任务、项目、定时任务 | 看板/列表/表格任务管理、项目进度日历与一次性定时派发 |
| AI 团队 | 智能体、小队、Skills、运行时、发现与接入 | 员工建档授权、小队编排、技能库、并发策略与运行器接入 |
| 数字办公室 | 办公室、空间与工位 | 3D 实景监控、空间区域配置、自由布置/自建空间与工位总览 |
| 底部入口 | 统计、设置、帮助中心 | 三级 Token 预算账本、系统三栏设置与使用指南 |

### 任务、项目与讨论

- **多视图任务面板**：支持看板、列表（可折叠状态组）与表格（支持状态分组、列显隐、搜索及勾选/筛选结果 CSV 导出）三种视图并记忆偏好；子任务归属父任务详情管理，全部子任务验收或取消后父任务方可验收。
- **定时派发与前置依赖**：新建任务可配置一次性定时派发与前置任务；若前置未验收或负责人已暂停，系统将在条件满足时自动入队。
- **任务评论与 `@` 联动**：评论支持回复与 `@` 成员；`@` 真人发送站内通知（可选发邮件），`@` Agent 自动排队在同线程回复并计入其预算。
- **项目与日历**：项目页汇总各项目完成率、团队月历与当日安排，支持真人与 Agent 联合负责同一任务。

## 工作区设置与组织治理

设置采用 **「主导航 → 设置分类 → 内容」** 三栏布局，并保持全系统一致的暖石磨砂视觉规范：

| 分类 | 页面 |
| --- | --- |
| 个人设置 | 个人资料、偏好设置（外观 / 默认任务视图 / 时区）、通知 |
| 工作区管理 | 常规（名称 / 任务前缀 / 注入上下文）、成员、账号与权限 |
| 任务配置 | 任务状态、标签、属性（文本 / 数字 / 单选） |
| 连接与扩展 | 集成（GitHub）、MCP |
| 系统记录 | 操作记录（保留最近 100 条关键管理审计日志） |

- **原子化级联安全删除**：小队、Skills、MCP 服务、任务标签与自定义属性均支持在界面中确认删除，后端在单事务内自动解绑员工/任务/预算/区域关联引用并写入审计记录。
- **Skills 市场与手动导入**：在 **「AI 团队 → Skills」** 支持从 [Anthropic Skills](https://github.com/anthropics/skills)、[OpenAI Plugins](https://github.com/openai/plugins)、[Vercel Agent Skills](https://github.com/vercel-labs/agent-skills)、[skills.sh](https://skills.sh) 与 [SkillsMP](https://skillsmp.com) 固定 Git Commit 下载完整技能包（含配套脚本与参考文档，存于 `OFFICE_DATA_DIR/skill-packages/`），也支持上传 `SKILL.md` 或直接粘贴正文。
- **MCP 工具接入**：在 **「设置 → 连接与扩展 → MCP」** 添加 Streamable HTTP（HTTPS 或回环 HTTP，Bearer 鉴权通过 `OFFICE_MCP_*` 环境变量引用）或本机 stdio 服务，按工具名白名单授权给 Codex / Pi（需支持 `builtin:mcp`）。
- **GitHub 工作区授权**：在 **「设置 → 集成 → GitHub」** 绑定本机 `gh` 登录并按仓库与操作细粒度授权，智能体可在权限设置中进一步缩小范围，所有仓库读写、Issue 与 PR 操作均写入审计日志。详见 [GitHub 接入与权限说明](docs/GITHUB_INTEGRATION.md)。

## 运行器发现与远程机器采集

### 本机自动发现

在 **「发现与接入」** 默认每 10 秒扫描本机 PATH、常用安装目录与可见进程（可在「运行时」调整间隔或改为手动），支持识别 Codex、Pi、Claude Code、Gemini CLI、OpenCode、Aider、Cursor Agent、Copilot CLI、Qwen Code、Kiro CLI、OpenClaw、WorkBuddy、Antigravity。

新发现来源处于 **「待接入」**，管理员点击 **「接入运行器」** 后进入公司资源池，再在 **「智能体」** 创建员工并绑定，同一运行器可服务多位不同岗位的员工。本机 Codex / Pi 安装项支持平台直接派发任务；远程来源与运行中进程以 **「仅观察模式」** 纳入资产盘点。详见 [运行器接入与智能体绑定指南](docs/AGENT_ONBOARDING.md)。

### 跨主机采集客户端（`symbio`）

在 **「发现与接入 → 采集机器」** 安装客户端（要求 Node.js 22.13+）：

```sh
npm install -g symbio-agent-collector@0.2.0
symbio help
```

1. 如服务端仅监听本机回环地址，先在目标机器建立 SSH 隧道：`ssh -N -L 4318:127.0.0.1:4318 user@office-host`。
2. 在工作台点击 **「接入新机器」** 生成登录命令，并在目标主机执行 `symbio login '<采集基础地址>' --run` 输入一次性配对码（10 分钟有效，凭据保存在 `~/.agent-office/collector.json`）。
3. 常用命令：`symbio run`、`symbio status --json`、`symbio tasks list --status in_progress`、`symbio tasks show AG-12 --json`、`symbio agents list`、`symbio logout`。
4. **安全删除机器**：客户端离线且无员工绑定/活跃任务后可从机器表删除，保留历史任务与审计日志。

> 远程客户端当前支持运行器发现采集与只读任务查询，尚不支持远程任务派发。完整教程见 [远程机器接入与客户端使用指南](docs/REMOTE_COLLECTOR_GUIDE.md) 与 [CLI 说明](collector/README.md)。

## 执行沙箱、公共工作区交付与财务预算

- **隔离执行目录与演示模式**：每次任务执行在 `data/workspaces/<run-id>` 中独立运行；可为测试员工选择 **「演示运行器」** 在不消耗真实 Token 的情况下跑通全流程。
- **项目公共工作区与三方对比发布**：项目文件存放于 `OFFICE_DATA_DIR/project-space/`（单文件 ≤ 16 MiB，单项目当前版本合计 ≤ 100 文件 / 128 MiB）。派单时自动快照项目资料与前置依赖至 `.office-inputs/`；Codex 将产出写入 `deliverables/` 后进入 **「待发布」**，审核人可对比 **开工基线 / 当前版本 / 本次交付** 三方差异，发现并发改动冲突时可退回重跑或确认发布新版本。
- **人事、财务与多人会议**：将招聘类任务派给 **人事**（只读权限，可调用公司工具创建默认只读的新员工）；将额度核算派给 **财务**（查询账本并在公司总额内调整小队/个人额度）；在 **「聊天」** 选择 2 名员工发起双人交流，加入第 3 人自动转入会议室多轮发言并可一键转派后续任务。
- **三级预算预留机制**：任务启动前按公司、小队、员工三层校验并预留额度，执行中按运行器实际上报 Token 扣减，结束后释放多余预留。

## 技术架构与验证

```text
HTTP 操作 → SQLite 原子事务（业务状态、3D 布局与审计事件）
        → 调度队列 → 本机运行器（Codex App Server / Pi JSON 流 / 演示运行器）
        → 统一执行事件 → SQLite → SSE 增量推送 → 浏览器 3D / 看板视图
```

### 核心目录

- `src/`：Node.js ESM 服务端（HTTP/SSE 服务、SQLite 存储、任务调度、运行器协议适配、3D 家具/墙体/地板持久化、GitHub/MCP/Skills/采集模块）
- `public/`：Symbio 工作台前端（Three.js 3D 办公室引擎、磁吸自建空间交互、A\* 寻路、看板/项目/设置界面）
- `apogee/`：产品介绍、交互演示与使用说明主页（React + Vite + Tailwind + 复用真实 Three.js 3D 引擎）
- `collector/`：独立跨主机采集与只读查询 CLI（`symbio` / `symbio-agent-collector`）
- `test/`：Node 原生测试套件

```sh
# 校验主页 TypeScript 类型与生产构建
npm run typecheck
npm run build

# 运行全套单元测试
```
